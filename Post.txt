A high-performance C++20 utility designed to recursively scan directory trees, discover Git repositories, and provide instant status reports or path lookups.

Key Features

- **Recursive Scanning:** Efficiently traverses directory structures while automatically skipping heavy or irrelevant subdirectories (`build`, `build_deps`, `vcpkg`, `node_modules`, `.vs`, `.gradle`).
- **Intelligent Short Summary (`-s`):** Programmatically queries repository states using porcelain formats to output a clean, colored, single-line overview of the current branch, staged changes, modifications, and untracked files.
- **Indexed Lookups:** Pass a repository index to output its absolute path directly, making it ideal for shell scripting and automation workflows.
- **Robust & Safe:** Features safe path conversions for multi-byte code pages on Windows and RAII-based color management via `rang`.

Requirements & Usage

- **Requirements:** A C++20 compatible compiler supporting `<filesystem>` and `<print>`, the `rang` terminal styling library, and the Git CLI in your system `PATH`.
- **Scan All Repos:** `repo-scanner <parent-folder-path>`
- **Short Summary:** `repo-scanner <parent-folder-path> -s`
- **Path Lookup:** `repo-scanner <parent-folder-path> <repo-index>`
